## 试录和交付检查

1. 先本地试录驾驶舱、学生台、证据视图之间的切换，检查公式字号、页面停顿和横向画面；缺少真实结果时只标记为试录。
2. 用 T21 验收记录填写实际数字和任务 ID。选择证据页的学生、B 的转交任务、D 的待答题；账号提前登录，浏览器保持同一缩放。
3. 建议 1920×1080、30 fps，话筒单独校音。D 的两页并排，以便一眼看见预测和提交后的更新。失败就恢复新库重录；不要用旧录屏冒充此次实时结果。
4. 正式输出 MP4 前确认主办方提交规格。完整回看时长、五个场景、公式和声音；确认公网访问、教师学生权限和视频所示版本、快照一致。将版本、快照清单及试录/正片路径写入 [预跑记录](../reviews/T21-submission.md)。
