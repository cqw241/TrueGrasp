## 项目目标与当前进展

真懂 AI 面向高校高等数学，目标是由教学目标、作业和教学时钟主动驱动“发现风险 → 规划干预 → 可证伪诊断 → 针对性辅导 → 独立验证 → 延迟复测／跨章预检 → 必要时转教师”的连续闭环。学生主动提问是额外入口，不能成为直接索取答案的旁路；教师指令优先，人工处理也必须留下独立证据。验证 Agent 不接收辅导对话，掌握结论由证据驱动。
