## 证书与运维

当前 Let's Encrypt 证书包含公网 IP SAN，签发于 2026-11-10 15:06:39 UTC，到期时间为 **2026-11-17 07:06:38 UTC**。IP 证书有效期短，依赖 `truegrasp-ip-tls.timer` 每六小时检查，剩余不足 72 小时时签发替换。

本轮已验证 timer 启用、证书余量检查跳过签发，以及恢复标记拉起网关。没有为验收强制重新签发证书，因此不能把这次检查记为 ACME 完整续签成功。续签会短暂释放 443；发现 SSE 长连接拖延优雅退出后，配置 worker 最多等待 5 秒、systemd 最多等待 15 秒。维护切换期间会短暂出现连接失败，网关恢复后重新连接或刷新即可。
